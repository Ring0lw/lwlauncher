# LinusWare launcher

Replaces the [old whiptail launcher](https://git.catapis.uk/linusware/main/src/commit/2b7533cf146ca7dd41901b3f974c6aeca2bb83f7/launcher.sh)


## Build(Dev)
```sh
cargo build --release
```

## Install(User)
```bash
curl -fsSL https://linusware.org/install.sh | bash
```
